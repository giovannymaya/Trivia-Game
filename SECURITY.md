# Security Policy

## Reporting a vulnerability

Please do not open a public issue for security problems. Instead, use GitHub's
private vulnerability reporting: go to the **Security** tab of this repository
and choose **Report a vulnerability**.

## Scope

This is a static, client-side game with no backend and no user accounts. It
loads questions from the public [Open Trivia Database](https://opentdb.com/)
and stores high scores only in the player's own browser (`localStorage`).
