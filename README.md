# Maya Family Trivia Game 🎮
Inspired by son Bash, decided to create a fun and interactive trivia game perfect for family game nights! Test your knowledge across multiple categories with timed questions, sound effects, and competitive scoring.

### ✨ Features

- 👨‍👩‍👧‍👦 Family night mode: 2–6 players take turns on one device with a live scoreboard
- 📚 Multiple trivia categories, plus difficulty (easy / medium / hard), question type (multiple choice, true/false or mixed) and game length options
- ⚡ Points for speed and 🔥 streak bonuses
- ⏲️ Timer-based questions (30 seconds per question)
- 🎵 Interactive sound effects
- 🏆 Local high score tracking
- 📱 Responsive design for all devices
- 🎨 Space-themed, frosted-glass interface with animated feedback
- ⌨️ Keyboard shortcuts (1–4 or A–D) to answer
- 🥇 Leaderboard with medals and an end-of-game results screen

### 🎯 How to Play

- Pick **Solo** or **Family night** and enter the player names
- Choose a category, difficulty, question type and number of questions
- Answer each question within the 30-second time limit (in Family night, pass the device when it's the next player's turn)
- Get instant feedback on your answers
- Track your score and compete for high scores!

### 🧮 Scoring

- **100 points** for every correct answer
- **Speed bonus:** up to **+50** depending on how quickly you answer
- **Streak bonus:** **+25** for each correct answer in a row after the first (up to **+100**)
- A wrong answer or running out of time resets your streak

### 🛠️ Technologies Used

- Vanilla Javascript
- CSS3 with custom animations
- HTML5
- Local Storage for score persistence
- Open Trivia Database API used for questions
- Vercel used for deployment
